# 머니모니 — 개념 스토리 레이어 요구사양서 & 콘텐츠 기획

> 목적: 미니게임만으로는 15개 경제 개념을 "완전히 이해"시키기 어렵다는 문제를 해결하기 위해, 게임 진입 전(그리고 게임 종료 후)에 **이야기·비유·실생활 예시·시각자료**로 개념을 먼저 체감시키는 "개념 스토리 레이어"를 정의한다. 이 문서는 `docs/idea.md`(세계관·모듈), `docs/implementation.md`(기술 구현), `CLAUDE.md`/`docs/phases.md`(개발 규칙·로드맵)를 보완하는 문서이며, 15개 모듈 각각에 실제로 쓸 수 있는 스토리 초안까지 포함한다.

---

## 1. 문제 정의

지금까지 설계된 각 건물(모듈)의 "미니게임"은 조작(드래그, 룰렛, 타이밍)을 통해 개념을 체감시키는 데는 좋지만, 그 자체만으로는 개념이 왜 그렇게 동작하는지, 실제 삶에서 어떤 모습으로 나타나는지를 설명해주지 못한다. 초1~3 학생은 규칙을 몸으로 익히는 것과 그 규칙이 "왜" 존재하는지를 이해하는 것이 별개다. 게임 조작만 반복하면 "이렇게 하면 이긴다"는 패턴 학습에 그치고, 개념 자체(복리가 왜 시간이 갈수록 폭발적으로 커지는지, 인플레이션이 왜 생기는지, 주식이 회사와 무슨 관계인지)는 남지 않을 위험이 있다.

## 2. 해결 방향: 개념 스토리 씬

각 건물에 진입하면 미니게임 전에 **3~5개 장면으로 구성된 짧은 이야기(스토리 씬)**가 먼저 재생된다. 이 이야기는 다음 다섯 요소를 항상 포함한다.

1. **공감 상황(situation)** — 아이가 실제로 겪을 법한 장면에서 이야기를 시작한다(용돈, 친구, 간식, 가족).
2. **비유(metaphor)** — 개념을 손에 잡히는 사물/행동에 빗댄 한 문장을 이야기 속에서 캐릭터의 대사로 자연스럽게 던진다.
3. **실생활 예시(real example)** — "그거 우리도 겪어봤잖아"라고 느낄 구체적 사례를 덧붙인다.
4. **게임으로의 다리(bridge)** — 이야기의 마지막 장면이 "그래서 우리도 한번 해볼까?"로 자연스럽게 미니게임으로 이어진다.
5. **회고(recap)** — 미니게임이 끝난 뒤 결과 화면에서, 이야기 속 비유 문장을 캐릭터가 다시 한번 짧게 되짚어준다(2회 노출로 기억에 남긴다).

이야기는 만화처럼 3~5컷의 패널을 한 컷씩 넘겨보는 형식으로 구현하고, 각 컷에는 일러스트(또는 애니메이션)와 캐릭터 대사, 음성 내레이션이 함께 붙는다. 게임을 잘하는 것이 목표가 아니라 "이해하고 나서 게임으로 확인해보는 것"이 목표이므로, 스토리 씬 자체에는 정답을 맞히는 압박이 없다.

## 3. 유즈케이스

**유즈케이스 1 — 최초 방문**: 아이가 마을 지도에서 처음으로 어떤 건물(예: 은행)을 클릭한다. `/building/bank`에 진입하면 스토리 씬이 자동 재생된다. 아이는 화면을 탭해 한 컷씩 넘기며(또는 자동 재생 + 음성 내레이션을 듣는다) 이야기를 끝까지 본다. 마지막 컷에서 "이자가 뭔지 알아봤으니, 이제 저금통에 직접 넣어볼까?" 같은 대사와 함께 "미니게임 시작하기" 버튼이 나타난다.

**유즈케이스 2 — 재방문(스토리를 이미 본 경우)**: 아이가 나중에 같은 건물에 다시 들어오면, 스토리 씬은 자동으로 건너뛰고 바로 건물 메인 화면(미니게임 시작 버튼 + "이야기 다시보기" 버튼)이 뜬다. 매번 강제로 이야기를 다 봐야 한다면 반복 플레이가 지루해지기 때문이다. 다만 "이야기 다시보기" 버튼은 항상 남겨두어, 아이가 원하면 언제든 다시 볼 수 있게 한다.

**유즈케이스 3 — 게임 종료 후 회고**: 미니게임을 마치면 결과 화면(`/building/[id]/result`)에서 코인 보상과 함께, 스토리에 나왔던 캐릭터가 "아까 얘기했던 것처럼, oo은 △△와 같은 거였지?" 하고 비유 문장을 다시 짚어주는 한두 줄의 말풍선이 뜬다. 여기에 기존 `<ReflectionPrompt />`(왜 그렇게 선택했는지 묻는 하브루타식 질문)가 이어진다.

**유즈케이스 4 — 부모와 함께 보기**: 스토리 씬에는 소리 없이도 이해할 수 있도록 자막(대사 텍스트)이 항상 함께 표시되어, 부모가 소리 없이 화면만 보며 옆에서 설명을 덧붙이는 것도 가능하게 한다.

## 4. UI/인터랙션 요구사항

스토리 씬은 만화책처럼 세로로 긴 한 장의 배경 일러스트 위에, 컷마다 캐릭터와 말풍선이 순서대로 등장하는 방식으로 구현한다(완전히 다른 배경으로 컷이 바뀌는 슬라이드보다, 하나의 큰 장면 안에서 요소가 순차적으로 나타나는 편이 제작 비용이 낮고 몰입감도 좋다). 화면 하단에는 진행 바(예: "2/4")를 두고, 화면 아무 곳이나 탭하면 다음 대사로 넘어가며, 좌우 스와이프로도 이전/다음 컷 이동이 가능하게 한다. 각 컷 진입 시 사전 녹음된 내레이션 mp3가 자동 재생되고, 재생 중에는 해당 대사 텍스트에 가라오케 자막처럼 하이라이트가 들어가 읽기 학습도 자연스럽게 겸하게 한다. 스토리 전체를 건너뛰는 "건너뛰기" 버튼은 항상 우상단에 두되, 최초 방문에서는 한 번 확인 다이얼로그("정말 건너뛸까요? 이야기를 보면 게임이 더 쉬워져요!")를 띄워 무심코 건너뛰지 않게 한다.

## 5. 데이터 스키마 & 아키텍처 통합

라우팅 구조는 새로 만들지 않는다. `docs/implementation.md` 5장에서 정의한 `/building/[id]`가 그대로 "개념 스토리 뷰어 겸 미니게임 진입 화면" 역할을 하도록 역할을 명확히 하고, `data/buildings.ts`의 건물 메타데이터에 스토리 필드를 추가한다.

```ts
interface BuildingStoryScene {
  id: string;                 // "scene-1"
  speaker: "narrator" | string;   // "narrator" 또는 캐릭터 이름
  text: string;                // 화면에 보이는 대사/자막
  illustrationKey: string;     // 일러스트 자산 키 (제작 지시서와 매핑)
  animationHint?: string;      // 예: "동전이 통 안으로 굴러 들어감"
  audioKey: string;            // content/audio/{buildingId}-{sceneId}.mp3
}

interface BuildingContent {
  id: string;
  district: 1 | 2 | 3;
  title: string;
  metaphorLine: string;        // 이야기 속에서 강조되는 비유 한 문장 (UI에서 크게 강조 표시)
  realExample: string;         // 실생활 예시 한두 문장
  storyScenes: BuildingStoryScene[]; // 3~5개
  bridgeLine: string;          // 마지막 컷: 게임으로 넘어가는 대사
  recapLine: string;           // 게임 종료 후 결과 화면에서 다시 보여줄 대사
  // ...기존 필드(잠금조건, 보상 등)
}
```

`store`의 `buildings[id]`에는 `storySeen: boolean`(과 `storySeenAt?: string`)을 추가해 재방문 시 자동 스킵 여부를 판단한다(유즈케이스 2). 이 필드 추가는 `CLAUDE.md`의 "스키마 변경 시 기본값 지정 + version 증가" 규칙을 그대로 따른다.

## 6. 콘텐츠 제작 파이프라인

이야기 콘텐츠는 개발과 분리해 먼저 텍스트로 확정한다. 이 문서의 7장이 각 모듈의 1차 초안이며, 실제 제작 단계에서는 다음 순서를 권장한다. 먼저 이 문서의 대사를 기준으로 성우 녹음 대본을 뽑아 `content/audio/{buildingId}-scene-N.mp3`로 녹음/생성하고, 동시에 `animationHint`를 기준으로 일러스트레이터에게 컷별 그림 지시서를 전달하며, 마지막으로 개발자가 `data/buildings.ts`에 실제 텍스트·자산 키를 채워 넣는다. 이렇게 "글 대본 → 오디오/그림 자산 → 데이터 배선"의 순서를 지키면 카피 수정이 그림/코드보다 항상 먼저 끝나 手戻り(재작업)를 줄일 수 있다.

## 7. 15개 모듈별 스토리 콘텐츠 초안

아래 각 항목은 실제 대사 초안이다. `상황`은 이야기의 도입부, `이야기`는 컷별 대사 흐름(3~4컷), `비유`는 강조 문장, `실생활 예시`는 부가 설명, `게임 연결`은 마지막 대사, `회고`는 게임 종료 후 대사다. 톤은 반말로 친근하게, 초1도 이해할 짧은 문장으로 통일했다.

### 7-1. 화폐의 역사 (`museum`)

**상황**: 아이 캐릭터가 박물관 앞에서 할아버지 저금통 캐릭터를 만난다. "옛날엔 돈이 지금이랑 완전 달랐어!"

**이야기**:
1. (내레이터) 아주 먼 옛날, 사람들은 조개껍데기로 물건을 바꿨어요.
2. (할아버지 저금통) 근데 내가 조개 10개를 줘도, 상대방이 조개 말고 생선을 원하면 어떡하지? 못 바꾸는 거야!
3. (내레이터) 그래서 사람들은 누구나 좋아하는 동전, 그다음엔 지폐를 만들었어요. 요즘은 카드나 폰으로도 돈을 내죠.
4. (할아버지 저금통) 돈이 바뀐 이유는 딱 하나야 — "더 편하게 바꾸려고"!

**비유**: "돈은 '내가 가진 것'과 '내가 원하는 것'을 편하게 바꿔주는 마법의 다리야."

**실생활 예시**: 마트에서 카드 한 장으로 뭐든지 살 수 있는 것처럼, 옛날엔 그 '한 장'이 조개, 동전, 지폐로 계속 바뀌어온 것뿐이다.

**게임 연결**: "그럼 우리도 옛날 시장에 가서 직접 물건을 바꿔볼까?"

**회고**: "아까 봤지? 돈은 계속 '더 편한 모습'으로 바뀌어왔다는 거!"

### 7-2. 가계부 (`ledger-house`)

**상황**: 아이 캐릭터가 하루 동안 용돈을 받고, 간식을 사 먹는 장면을 오두막 캐릭터(가계부 요정)가 옆에서 지켜본다.

**이야기**:
1. (가계부 요정) 오늘 용돈 500원 받았지? 이건 초록 화살표! 들어온 돈이야.
2. (가계부 요정) 그런데 아까 젤리 사 먹었잖아. 그건 빨간 화살표, 나간 돈!
3. (가계부 요정) 초록이 많으면 저금통이 통통해지고, 빨강이 너무 많으면 홀쭉해져.
4. (아이 캐릭터) 그럼 나는 오늘 어떻게 됐는지 한번 적어볼래!

**비유**: "가계부는 내 돈이 어디서 왔다가 어디로 갔는지 그려주는 지도야."

**실생활 예시**: 문구점에서 500원짜리 지우개를 사면, 그 순간 지도에 빨간 화살표 하나가 그려지는 셈이다.

**게임 연결**: "오늘 하루 동전들이 어디로 가는지, 우리가 직접 화살표를 그려볼까?"

**회고**: "초록 화살표, 빨간 화살표! 이제 어디로 갔는지 한눈에 보이지?"

### 7-3. 용돈 배분 (`allowance-square`)

**상황**: 아이 캐릭터가 용돈을 받자마자 전부 장난감에 써버렸다가, 다음 날 친구 생일선물을 살 돈이 없어 곤란해지는 짧은 사건이 먼저 벌어진다.

**이야기**:
1. (아이 캐릭터, 속상해하며) 어제 다 써버려서 민지 생일선물을 못 사겠어…
2. (촌장) 그래서 마을 사람들은 돈이 생기면 네 개의 항아리에 나눠 담아. 쓸 돈, 갖고 싶은 것, 저금, 그리고 나눔.
3. (촌장) 한 항아리에만 몰빵하면 꼭 이런 일이 생기더라고.
4. (아이 캐릭터) 그럼 이번엔 나눠서 담아볼래!

**비유**: "용돈은 한 바구니가 아니라 네 개의 작은 항아리에 나눠 담는 거야 — 오늘 쓸 돈, 나중에 살 것, 모아둘 돈, 나눠줄 돈."

**실생활 예시**: 세뱃돈을 받으면 다 쓰지 않고 일부는 저금하고 일부는 부모님과 함께 기부하는 것도 같은 원리다.

**게임 연결**: "이번 주 용돈이 들어왔어! 네 항아리에 어떻게 나눠 담을지 직접 해보자."

**회고**: "한 곳에만 담지 않고 나누니까, 이번엔 민지 선물도 살 수 있었지?"

**보너스 에피소드 — 가치소비**

**상황**: 아이 캐릭터가 장난감 가게 앞에서 반짝이는 장난감을 보고 바로 사고 싶어 안달이 난다.

**이야기**:
1. (아이 캐릭터) 와, 저거 완전 반짝여! 지금 당장 사야 해!
2. (촌장) 잠깐, 그거 어제도 그렇게 말했던 것 같은데?
3. (아이 캐릭터) 어… 그러고 보니 어제 다른 것도 그렇게 사고 싶었는데, 지금은 기억도 안 나요.
4. (촌장) 그래서 하루만 참고 다시 생각해보는 습관이 좋아. 정말 필요한 건지, 그냥 순간 반짝여서 그런 건지 알 수 있거든.

**비유**: "가치소비는 사기 전에 마음에게 한 번 더 물어보는 거야 — '이거 진짜 나한테 필요해?'"

**실생활 예시**: 장난감 가게에서 당장 사고 싶은 걸 참고, 집에 와서도 계속 생각나는지 하루 지켜본 뒤 결정하는 것.

**게임 연결**: "이번 주 용돈, 바로 다 쓰고 싶은 마음을 하루만 참아볼까?"

**회고**: "하루 참아보니 어땠어? 진짜 갖고 싶었어, 아니면 그냥 반짝여서 그랬어?"

### 7-4. 저축과 이자 (`bank`)

**상황**: 아이 캐릭터가 짝꿍에게 지우개를 하루 빌려주고, 다음 날 짝꿍이 "고마워서" 새 지우개를 하나 더 얹어 돌려주는 장면.

**이야기**:
1. (짝꿍) 어제 지우개 빌려줘서 고마워! 이거 새 지우개 하나 더 줄게.
2. (아이 캐릭터) 어? 빌려준 것보다 더 받았네?
3. (은행 캐릭터) 그게 바로 '이자'야! 은행도 네가 돈을 맡겨두면, 고마워서 조금 더 얹어줘.
4. (은행 캐릭터) 맡겨두는 시간이 길수록, 은행이 더 자주 고마움을 표현하지.

**비유**: "이자는 은행이 '고마워, 잠깐 맡겨줘서'라고 건네는 작은 보너스야."

**실생활 예시**: 저금통에 돈을 넣어두기만 해도, 은행 계좌에 넣어두면 시간이 지나 조금씩 늘어나 있는 걸 볼 수 있다.

**게임 연결**: "그럼 우리도 저금통에 얼마나 맡겨야 얼마나 고마움을 받을 수 있는지 볼까?"

**회고**: "맡겨두기만 했는데 조금 늘어 있었지? 그게 이자야!"

### 7-5. 복리 (`money-tree`)

**상황**: 아이 캐릭터가 겨울에 작은 눈덩이를 언덕 위에서 굴리기 시작한다. 처음엔 주먹만 하던 눈덩이가 구를수록 점점 커진다.

**이야기**:
1. (아이 캐릭터) 처음엔 이렇게 작았는데… 어? 구를수록 왜 이렇게 빨리 커지지?
2. (머니나무 정령) 눈이 눈을 더 붙게 만들거든. 커질수록, 더 빨리 커져!
3. (머니나무 정령) 돈도 똑같아. 이자로 받은 돈을 다시 저금하면, 그 이자가 또 이자를 만들어.
4. (머니나무 정령) 그래서 우리 마당의 이 나무도, 열매를 다시 심을 때마다 가지가 훨씬 빨리 갈라지는 거야.

**비유**: "복리는 언덕에서 구르는 눈덩이야 — 커질수록 더 빨리 커져."

**실생활 예시**: 세뱃돈을 안 쓰고 계속 저금만 해도 늘지만, 이자까지 계속 다시 저금하면 몇 년 뒤엔 훨씬 큰 차이가 난다.

**게임 연결**: "우리 마당의 머니나무도 한번 키워볼까? 열매를 먹을지, 다시 심을지는 네가 골라봐."

**회고**: "다시 심을 때마다 나무가 더 빨리 자랐지? 그게 눈덩이처럼 커지는 복리야."

### 7-6. 소득의 종류 (`job-center`)

**상황**: 세 캐릭터(일꾼, 사장님, 농장주)가 같은 아침에 각자 다른 하루를 시작한다.

**이야기**:
1. (일꾼) 나는 오늘도 마을 청소를 해야 돈을 벌어. 안 하면 한 푼도 못 벌지.
2. (사장님) 나는 레모네이드 가판대를 운영해. 잘 팔리면 많이 벌고, 안 팔리면 적게 벌어.
3. (농장주) 나는… 씨앗을 심어놨더니, 오늘은 낮잠만 자도 나무가 알아서 열매를 만들어줘!
4. (내레이터) 몸을 움직여 버는 돈, 내가 사장이 되어 버는 돈, 내 재산이 스스로 벌어다 주는 돈 — 셋 다 다른 종류의 소득이에요.

**비유**: "일꾼은 몸으로, 사장님은 아이디어로, 농장주는 심어둔 나무로 돈을 벌어."

**실생활 예시**: 부모님이 회사에 다니며 월급을 받는 것(근로소득), 작은 가게를 운영하는 것(사업소득), 은행에 맡긴 돈이 이자를 버는 것(자본소득)이 모두 이 세 가지 예다.

**게임 연결**: "오늘 하루, 셋 중 한 명이 되어서 직접 살아볼까?"

**회고**: "똑같이 하루를 보냈는데 버는 방법이 다 달랐지? 나중엔 이 세 가지를 다 가질 수도 있어."

**보너스 에피소드 — 세금**

**상황**: 하루 일을 마친 일꾼·사장님·농장주가 받은 돈을 세어보다가, 손에 쥔 돈이 처음 말했던 것보다 조금 적다는 걸 알게 된다.

**이야기**:
1. (일꾼) 어라? 분명 100원 번다고 했는데, 손에 90원밖에 없어!
2. (촌장) 그 10원은 세금으로 걷혔어. 다 함께 쓰는 학교, 도로, 놀이터를 만드는 데 쓰이지.
3. (사장님) 나도 가판대에서 번 돈 중 일부를 세금으로 냈어. 근데 저 놀이터, 나도 매일 쓰잖아?
4. (촌장) 맞아! 다 같이 조금씩 냈으니까, 다 같이 쓸 수 있는 거야.

**비유**: "세금은 마을 사람들이 조금씩 걷어서 다 같이 쓰는 놀이터를 만드는 것과 같아."

**실생활 예시**: 우리 반이 학급 화폐로 나라 놀이를 하면서, 번 돈의 일부를 모아 학급 행사비로 쓰는 것도 세금과 같은 원리다.

**게임 연결**: "오늘 번 돈에서 세금이 얼마나 빠지는지, 우리도 직접 확인해볼까?"

**회고**: "번 돈이 다 내 손에 오는 게 아니었지? 그 대신 다 같이 쓰는 것들이 생겼어."

### 7-7. 인플레이션 (`market`)

**상황**: 아이 캐릭터가 지난달엔 200원이던 아이스크림이 이번 달엔 300원이 된 걸 발견하고 놀란다.

**이야기**:
1. (아이 캐릭터) 어? 저번 달엔 200원이었는데 왜 300원이 됐지? 내 돈이 줄어든 것도 아닌데!
2. (시장 아주머니) 물건값이 조금씩 오르는 걸 '인플레이션'이라고 해. 재료값도 오르고, 사려는 사람도 많아졌거든.
3. (시장 아주머니) 그러니까 같은 100원이라도, 시간이 지나면 살 수 있는 게 조금씩 줄어드는 거야.
4. (아이 캐릭터) 그럼 저금통에만 오래 넣어두면… 내 돈으로 살 수 있는 게 줄어드는 거야?

**비유**: "인플레이션은 풍선에서 바람이 조금씩 빠지는 것과 같아. 똑같은 100원인데, 살 수 있는 힘이 야금야금 줄어."

**실생활 예시**: 몇 년 전 500원이던 과자가 지금은 1,000원이 된 것도 인플레이션 때문이다.

**게임 연결**: "물가 요정이 나타났어! 요정이 방해하기 전에 100원으로 사탕을 최대한 사보자."

**회고**: "값이 계속 오르니까 서둘러야 했지? 그래서 어른들은 돈을 그냥 두지 않고 불릴 방법을 찾는 거야."

**보너스 에피소드 — 원가·이윤·동업 (오리지널 캐릭터 "레몬이"·"설탕이")**

**상황**: 마을 두 어린이 "레몬이"와 "설탕이"가 함께 레모네이드 가판대를 열기로 한다(완전 창작 캐릭터 — 특정 책의 인물과 무관).

**이야기**:
1. (레몬이) 레몬이랑 설탕, 컵을 사는 데 500원 썼어. 이게 '원가'래.
2. (설탕이) 나는 손님 부르는 걸 잘하니까 내가 소리치고, 너는 레모네이드 만드는 걸 잘하니까 네가 만들자!
3. (레몬이) 그렇게 둘이 나눠서 하는 걸 '동업'이라고 하나 봐. 혼자 하는 것보다 훨씬 낫다!
4. (설탕이) 다 팔고 나니 800원! 원가 500원을 빼면… 300원이 남았어. 이게 '이윤'이래!

**비유**: "이윤은 산 가격과 판 가격 사이에 남는 틈이고, 동업은 잘하는 걸 나눠서 함께 하는 거야."

**실생활 예시**: 문구점 주인이 지우개를 300원에 사와서 500원에 팔면 200원이 남는 것도 같은 원리다.

**게임 연결**: "우리도 레모네이드 가판대를 열어서, 얼마에 팔아야 이윤이 남는지 직접 정해볼까?"

**회고**: "둘이 나눠서 하니까 더 잘됐지? 그리고 판 값에서 원가를 빼면 이윤이 남는다는 것도 기억해두자!"

### 7-8. 자본 (`capital-warehouse`)

**상황**: 빵집 아저씨가 손으로만 반죽하는 이웃과, 오븐(도구)을 가진 자신을 비교해서 보여준다.

**이야기**:
1. (빵집 아저씨) 오븐이 없던 시절엔 손으로만 빵을 구웠어. 하루에 열 개도 힘들었지.
2. (빵집 아저씨) 근데 오븐을 산 뒤부터는 하루에 백 개도 구울 수 있게 됐어!
3. (빵집 아저씨) 이 오븐처럼, 돈을 더 버는 데 쓰이는 도구나 재산을 '자본'이라고 해.
4. (내레이터) 트랙터, 가게, 심지어 저금해둔 돈도 다 자본이 될 수 있어요.
5. (건물지기 아주머니) 나는 오븐 대신 이 건물을 갖고 있어. 가게 하는 사람들이 여기서 장사하는 대가로 매달 조금씩 나한테 줘.
6. (아이 캐릭터) 그것도 오븐처럼, 아주머니 대신 돈을 벌어다 주는 거네요!
7. (건물지기 아주머니) 맞아. 땅이나 건물처럼 그 자리에 딱 있는 재산도 자본이 될 수 있어.

**비유**: "자본은 나 대신 일을 더 많이 해주는 도구야."

**추가 비유(부동산)**: "부동산은 그 자리에 딱 서서 매달 조금씩 고마움을 받는 든든한 땅이야."

**실생활 예시**: 배달 아저씨의 오토바이, 농부의 트랙터, 우리 마을 은행에 모인 저축도 모두 자본의 예다.

**게임 연결**: "여러 직업의 도구들을 구경하며, 도구가 있고 없고에 따라 무엇이 달라지는지 비교해볼까?"

**회고**: "같은 시간, 같은 사람인데 도구(자본)가 있으니까 결과가 크게 달랐지?"

### 7-9. 투자란 무엇인가 (`seed-field`)

**상황**: 농장주 캐릭터가 씨앗 한 줌을 들고, 저금통과 씨앗밭 중 어디에 넣을지 아이에게 묻는다.

**이야기**:
1. (농장주) 이 씨앗, 안전한 항아리에 넣어둘 수도 있고, 밭에 심을 수도 있어.
2. (농장주) 항아리에 두면 그대로지만 안전해. 밭에 심으면 크게 자랄 수도 있지만, 날씨가 나쁘면 시들 수도 있어.
3. (아이 캐릭터) 그럼 다 심는 것도, 다 항아리에 두는 것도 아니고… 나눠서 해볼래!
4. (농장주) 참, 한 가지만 꼭 기억해. 이 씨앗은 내일 밥 지을 쌀이 아니라, "당분간 안 써도 되는" 여유 씨앗이어야 해.
5. (아이 캐릭터) 왜요?
6. (농장주) 밭에 심으면 언제 열매가 열릴지 몰라. 당장 필요한 걸 심어버리면, 열매가 늦게 열렸을 때 곤란해지거든.

**비유**: "저축은 안전한 항아리, 투자는 결과를 알 수 없는 씨앗을 심는 것과 같아."

**추가 비유(여유자금)**: "투자는 당장 필요 없는 여유 씨앗으로 하는 거야 — 내일 먹을 쌀로 하면 안 돼."

**실생활 예시**: 세뱃돈을 그대로 저금하면 안전하게 그대로 남지만, 어른들이 그 돈의 일부를 투자하면 더 크게 불어날 수도, 줄어들 수도 있다.

**게임 연결**: "씨앗을 심어볼까? 풍년일지 흉년일지는 심어봐야 알아."

**회고**: "심을 때마다 결과가 달랐지? 그래서 투자는 씨앗 하나에 다 걸지 않는 게 중요해."

### 7-10. 주식 (`stock-street`)

**상황**: 아이가 좋아하는 가상의 과자 회사 "짱구과자"가 신제품을 내놓으려 한다.

**이야기**:
1. (짱구과자 사장) 이 회사는 케이크처럼 여러 조각으로 나뉘어 있어. 그 조각 하나하나가 '주식'이야.
2. (짱구과자 사장) 신제품이 인기를 끌면 회사가 잘돼서, 그 조각의 가치도 커져!
3. (짱구과자 사장) 근데 맛이 없으면? 조각도 작아지지…
4. (아이 캐릭터) 그럼 내가 어떤 조각을 갖고 있으면, 그 회사가 잘되길 응원하게 되겠네!
5. (짱구과자 사장) 참, 하나만 조심해. 갑자기 다들 "이거다!" 하고 우르르 몰리는 조각은 조심해야 해. 이미 값이 잔뜩 오른 다음일 때가 많거든.
6. (아이 캐릭터) 그럼 어떻게 해요?
7. (짱구과자 사장) 유행보다는, 이 회사가 진짜 좋아지고 있는지를 먼저 봐. 그리고 인기가 없어서 값이 쌀 때 눈여겨봐 두는 사람들도 있어.

**비유**: "주식은 회사를 나눈 케이크 조각 하나야. 회사가 잘되면 내 조각도 커져."

**추가 비유(급등 테마 경계)**: "우르르 몰릴 때 같이 뛰기보다, 이미 잘 자라고 있는 나무를 미리 알아보는 게 더 지혜로워."

**실생활 예시**: 내가 좋아하는 과자 회사, 게임 회사가 신제품으로 큰 인기를 끌면 그 회사의 주식을 가진 사람들도 함께 좋은 소식을 듣게 된다.

**게임 연결**: "짱구과자의 신제품 아이디어에 투표해보고, 다음 날 케이크가 어떻게 변하는지 지켜보자."

**회고**: "회사가 잘되니까 조각도 커졌지? 그게 주식이 움직이는 이유야."

### 7-11. ETF/ETN (`etf-lab`)

**상황**: 아이가 좋아하는 과자 한 가지만 잔뜩 샀는데, 하필 그 과자가 단종되어 속상해하는 장면.

**이야기**:
1. (아이 캐릭터) 좋아하는 과자만 잔뜩 샀는데, 이거 하나가 별로면 다 별로잖아…
2. (가게 이모) 그래서 사람들은 여러 과자를 조금씩 섞은 '종합선물세트'를 사기도 해.
3. (가게 이모) 하나가 별로여도, 다른 게 맛있으면 덜 아쉽잖아?
4. (내레이터) 여러 회사(자산)를 한 바구니에 담아 나눠 갖는 방법을 ETF라고 해요.
5. (사계절 농부) 얘들아, 나는 작물을 한 가지만 심지 않아.
6. (아이 캐릭터) 왜요? 제일 잘 자라는 것만 심으면 되잖아요!
7. (사계절 농부) 문제는, 다음에 무슨 계절이 올지 미리 정확히는 알 수 없다는 거야. 봄엔 새싹 작물이, 여름엔 뜨거운 작물이, 가을엔 단단한 작물이, 겨울엔 저장 작물이 강해.
8. (사계절 농부) 그래서 나는 여러 계절에 강한 작물들을 골고루 심어둬. 그럼 어떤 계절이 와도 밭 전체가 크게 흔들리지 않아 — 이게 바로 '포트폴리오'야.

**비유**: "ETF는 여러 과자를 조금씩 섞은 종합선물세트야. 하나가 별로여도 바구니 전체는 덜 흔들려."

**추가 비유(포트폴리오)**: "포트폴리오는 다음 계절을 맞히는 게 아니라, 어떤 계절이 와도 버티도록 미리 골고루 심어두는 큰 농장이야."

**실생활 예시**: 한 회사에만 다 걸었다가 그 회사가 안 좋아지면 크게 실망하지만, 여러 회사를 조금씩 나눠 가지면 덜 불안하다.

**추가 실생활 예시(포트폴리오)**: 용돈을 장난감 하나에 다 쓰지 않고 책, 저금, 나눔에도 나눠두면, 장난감이 금방 질려도 다른 즐거움이 남아있는 것과 비슷하다.

**게임 연결**: "여러 과자 카드로 나만의 바구니를 만들어보고, 한 종류만 골랐을 때랑 비교해보자."

**회고**: "바구니로 만드니까 덜 출렁였지? 그게 나눠 담는 이유야."

### 7-12. 금 (`gold-vault`)

**상황**: 시간여행 장면 — 왕이 다스리던 옛날부터 지금까지, 여러 시대의 사람들이 똑같이 반짝이는 금덩이를 소중히 여기는 모습이 이어진다.

**이야기**:
1. (내레이터) 아주 먼 옛날 왕도, 오래전 상인도, 지금의 어른들도 이 반짝이는 금을 소중히 여겼어요.
2. (금 캐릭터) 다른 돈의 가치가 흔들릴 때도, 나는 오랫동안 사람들의 믿음을 지켜왔지.
3. (금 캐릭터) 그래서 사람들은 걱정될 때 나를 찾아와.

**비유**: "금은 아주 오래전부터 지금까지 사람들이 계속 믿어온 반짝이는 약속이야."

**실생활 예시**: 결혼반지나 돌 반지처럼, 금은 오래 두어도 가치가 잘 사라지지 않는다고 여겨져 특별한 날 선물로도 많이 쓰인다.

**게임 연결**: "여러 시대를 지나오는 동안 금이 어떻게 반짝임을 지켜왔는지 함께 볼까?"

**회고**: "다른 것들은 변해도 금은 오래오래 믿음을 지켰지?"

### 7-13. 코인 / 스테이블코인 (`coin-station`)

**상황**: 아이 캐릭터가 스마트폰 화면 속으로 쏙 들어가 눈에 보이지 않는 동전을 만난다.

**이야기**:
1. (디지털 동전) 나는 종이도 금속도 아니야. 인터넷 속 컴퓨터에 기록된 동전이지.
2. (디지털 동전) 근데 나는 롤러코스터처럼 가격이 확 올랐다가 확 내려가기도 해!
3. (조용한 동전) 나는 조금 달라. 내 가격은 진짜 돈(달러)에 꽉 묶여 있어서 출렁임이 훨씬 적어.
4. (내레이터) 나 같은 걸 '스테이블코인'이라고 불러요.

**비유**: "일반 코인은 롤러코스터, 스테이블코인은 잔잔한 튜브 물놀이 트랙과 같아."

**실생활 예시**: 롤러코스터를 타면 스릴 있지만 무섭기도 한 것처럼, 코인 가격도 크게 흔들려서 어른들도 신중하게 다룬다.

**게임 연결**: "롤러코스터 코인과 튜브 트랙 스테이블코인, 둘 다 타보고 도착했을 때 소지금이 어떻게 다른지 비교해보자."

**회고**: "출렁임이 컸던 쪽과 잔잔했던 쪽, 뭐가 다르게 느껴졌어?"

### 7-14. 대출과 레버리지 (`loan-counter`)

**상황**: 아이 캐릭터가 친구 파티에 케이크를 더 크게 만들고 싶은데 재료가 모자란다.

**이야기**:
1. (아이 캐릭터) 케이크를 더 크게 만들고 싶은데 재료가 모자라…
2. (친구) 내 케이크 조각을 빌려줄게! 대신 내일은 원래보다 조금 더 갚아야 해.
3. (아이 캐릭터) 오, 오늘 파티는 더 커졌다! 근데 내일 갚을 걸 생각하니 조금 걱정도 되네.
4. (지렛대 아저씨) 내 돈에 빌린 돈을 더하면 더 큰 걸 할 수 있어. 대신 잘못되면 원래보다 더 크게 잃을 수도 있지.

**비유**: "대출은 친구에게 케이크를 빌리고 내일 조금 더 갚기로 하는 약속이고, 레버리지는 지렛대로 원래보다 훨씬 무거운 걸 드는 것과 같아."

**실생활 예시**: 어른들이 집을 살 때 은행에서 돈을 빌리고 나중에 이자와 함께 갚아나가는 것도 대출의 예다.

**게임 연결**: "지렛대로 돌을 들어보자. 너무 욕심내면 저울이 반대로 기울 수도 있으니 조심해야 해."

**회고**: "빌리니까 더 크게 할 수 있었지만, 갚을 것도 더 커졌지? 그게 대출과 레버리지의 양면이야."

**보너스 에피소드 — 신용**

**상황**: 아이 캐릭터가 지렛대 아저씨에게 물건을 빌리러 갔는데, 아저씨가 순순히 빌려주는 걸 보고 궁금해한다.

**이야기**:
1. (아이 캐릭터) 아저씨는 왜 저한테 선뜻 빌려주세요? 저 처음 보는 사이인데.
2. (지렛대 아저씨) 아니야, 너 저번에 빌린 거 딱 약속한 날 갚았잖아! 그게 쌓인 거야.
3. (지렛대 아저씨) 그런 걸 '신용'이라고 해. 약속을 잘 지킬수록 다음엔 더 쉽게, 더 많이 빌릴 수 있어.
4. (아이 캐릭터) 그럼 한 번이라도 안 갚으면… 다음엔 안 빌려주시겠네요?
5. (지렛대 아저씨) 맞아. 그래서 신용은 한 번에 와르르 쌓이는 게 아니라, 약속을 지킬 때마다 한 칸씩 쌓이는 계단 같은 거야.

**비유**: "신용은 '나중에 꼭 갚을게'라는 약속을 지킬 때마다 한 칸씩 쌓이는 계단이야."

**실생활 예시**: 문방구 아저씨가 자주 오는 단골에게 "다음에 와서 줘도 돼"라고 외상을 주는 것도 그동안 쌓인 신용 덕분이다.

**게임 연결**: "이번엔 네 신용 계단이 몇 칸까지 쌓이는지 지켜보자."

**회고**: "약속을 지킬 때마다 계단이 한 칸씩 올라갔지? 신용은 그렇게 천천히, 확실하게 쌓는 거야."

### 7-15. 자본주의·사회주의·공산주의 (`triple-village`)

**상황**: 세 마을(자본주의 마을, 사회주의 마을, 공산주의 마을)에서 똑같이 빵집을 운영하는 하루가 나란히 펼쳐진다.

**이야기**:
1. (내레이터) 세 마을 모두 빵을 만들어요. 하지만 만든 빵을 나누는 방법은 서로 달라요.
2. (자본주의 마을 촌장) 우리 마을에선 각자 자기 가게를 운영해. 더 맛있게, 더 재밌게 만든 사람이 손님을 더 많이 데려가지.
3. (사회주의 마을 촌장) 우리 마을에선 만든 빵을 모아서 다 같이 똑같이 나눠. 누가 더 열심히 만들어도 결과는 같아.
4. (공산주의 마을 촌장) 우리 마을엔 아예 '내 가게'가 없어. 다 함께 짓고, 다 함께 나눠.

**비유**: "세 마을은 같은 빵을 굽지만, '누가 얼마나 가질지'를 정하는 규칙이 서로 다른 거야."

**실생활 예시**: 조별 과제를 했을 때 잘한 사람이 더 칭찬받는 것과, 다 같이 똑같이 나누는 것 중 어느 쪽이 더 좋았는지 떠올려보면 이해가 쉽다.

**게임 연결**: "세 마을을 오가며 똑같이 빵집을 운영해보고, 어떤 게 다른지 직접 느껴보자."

**회고**: "세 마을 다 해봤지? 뭐가 더 좋다고 딱 잘라 말하긴 어려워. 각자 장단점이 있으니, 네 생각은 어때?" *(정답을 알려주지 않고 `<ReflectionPrompt />`로 자연스럽게 연결한다.)*
