# 투자 마인드 & 포트폴리오·경제 사계절 — 콘텐츠 설계 문서

> 목적: 저점매수·고점매도, 성장하는 회사를 사는 것, 급등 테마를 쫓지 않는 것, 생활에 지장 없는
> 돈으로만 투자하는 것 같은 **투자자의 마음가짐**과, 주식·부동산·코인·금·원자재로 구성하는
> **포트폴리오**, 그리고 "경제에도 계절이 있다"는 **경제 사이클** 개념을 머니모니에 추가한다.
> 이미 구현되어 있는 `seed-field`/`stock-street`/`etf-lab`/`gold-vault`/`capital-warehouse`
> 건물과 지식 도감 인터랙티브 레이어(`docs/almanac-interactive.md`) 위에 쌓는 설계다 — 새
> 건물은 만들지 않는다.

---

## 1. 콘텐츠 안전 원칙 — 반드시 먼저 읽을 것

이 주제는 일반 금융 개념(이자, 인플레이션 등)보다 조심스럽다. "어느 시점엔 어떤 투자를
해야 하는지"를 다루되, **실제 매매 타이밍을 알려주는 도구가 아니라 "경제는 이렇게 순환해왔다"는
일반 지식**으로만 다뤄야 한다. 이 원칙은 문서 전체에 적용되고, 실제 카피 작성 시에도 반드시
지켜야 한다.

1. **이 앱은 실시간 시세를 다루지 않는다.** 실제 주가·코인 가격·환율과 연동되지 않으므로,
   "지금 사라/팔라"는 신호를 줄 수 있는 구조 자체가 없다. 모든 콘텐츠는 역사적으로 관찰된
   일반적인 경향을 설명하는 것이지, 예측이나 추천이 아니다.
2. **"경제 계절"은 예측 도구가 아니라 분산의 이유로 가르친다.** "다음에 무슨 계절이 올지
   미리 알 수 없기 때문에, 한 가지에 몰빵하지 않고 여러 자산에 나눠 담는다"는 결론으로
   항상 귀결시킨다 — "지금은 겨울이니 이걸 사라"는 식의 결론은 절대 만들지 않는다.
3. **마인드(태도) 콘텐츠는 적극적으로, 자산 배분 콘텐츠는 "예시 하나"로 보수적으로.** 저점매수·
   고점매도 규율, 급등 테마 경계, 여유자금 원칙, 인내심은 시대·시장과 무관하게 항상 유효한
   "태도"이므로 자신 있게 가르친다. 반면 구체적인 자산 비중(예: "주식 30%, 채권 40%…")은
   특정 포트폴리오를 추천하는 것처럼 보일 수 있어 **비중 숫자를 아이 화면에 직접 노출하지
   않는다** — "여러 개를 섞는다"는 원리만 가르치고, 실제 비율은 다루지 않는다.
4. **`CLAUDE.md` 절대 규칙 7의 정신을 그대로 확장한다.** 기존에 `triple-village`(자본주의·
   사회주의·공산주의)에 적용했던 "정답 판정 금지, `<ReflectionPrompt />`로만 마무리"를 이번
   콘텐츠에도 동일하게 적용한다 — "이 시기엔 주식이 답이다" 같은 단정적 결론을 내리지 않는다.
5. **부모용 안내 문구를 추가한다.** `/parent` 화면에 "이 앱은 실제 투자 조언이 아니라, 투자의
   기본 개념과 마음가짐을 다루는 교육용 콘텐츠입니다"라는 한 줄을 명시적으로 추가한다.

## 2. 다루는 개념과 기존 앱 요소 매핑

| 요청 개념 | 기존에 있었나? | 어디에 넣을까 |
|---|---|---|
| 싸게 사서 비싸게 팔기(저점매수·고점매도) | 얕게만 있음(`seed-field`에 "심을 때마다 결과가 다르다"는 있지만 가격 타이밍 개념은 없음) | `stock-street`에 신규 장면 |
| 성장하는 회사를 사는 것 | `stock-street` 스토리에 이미 있음("회사가 잘되면 조각도 커져") | 기존 내용 재사용, 장면 하나만 보강 |
| 급등 테마를 쫓지 않는 것 | 없음 | `stock-street` 신규 장면 |
| 생활에 지장 없는 돈으로 투자하기(여유자금) | 없음 | `seed-field` 신규 장면 |
| 부동산 | 없음(자산군 자체가 없음) | `capital-warehouse`에 신규 장면 + 신규 용어 |
| 코인 | 있음(`coin-station`) | 변경 없음, 포트폴리오 논의에서 언급만 |
| 금 | 있음(`gold-vault`) | 변경 없음, 원자재의 사촌으로 짧게 연결 |
| 원자재 | 없음 | `gold-vault`에 짧게 추가 + 신규 용어 |
| 포트폴리오(여러 자산군을 섞기) | `etf-lab`에 "여러 회사"를 섞는 것만 있고, 자산군 자체를 섞는 개념은 없음 | `etf-lab`을 확장 — 이 문서의 핵심 |
| 경제 사이클/계절 | 없음 | `etf-lab`에 신규 "사계절 농부" 캐릭터 + 지식 도감 인터랙티브 위젯 |

**새 건물은 만들지 않는다.** `etf-lab`("여러 자산을 한 바구니에 담는 곳")이 포트폴리오·경제
사이클 콘텐츠의 자연스러운 확장 지점이라 여기로 집중시킨다.

## 5. `etf-lab` 확장 — "포트폴리오 실험실" + 사계절 농부

`etf-lab`(ETF 조합소)을 여러 회사를 섞는 것에서 **여러 자산군(주식/부동산/금/원자재)을
섞는 것**까지 다루도록 스토리를 확장한다. 새 오리지널 캐릭터 "사계절 농부"를 도입한다 — 기존
`job-center`의 "농장주" 캐릭터와는 별개로, 더 큰 농장을 운영하며 계절을 대비하는 경험 많은
농부로 설정한다.

### 5-1. 확장 스토리(기존 7-11 ETF 스토리 뒤에 이어붙임)

> 5. (사계절 농부) 얘들아, 나는 작물을 한 가지만 심지 않아.
> 6. (아이 캐릭터) 왜요? 제일 잘 자라는 것만 심으면 되잖아요!
> 7. (사계절 농부) 문제는, 다음에 무슨 계절이 올지 미리 정확히는 알 수 없다는 거야. 봄엔 새싹
>    작물이, 여름엔 뜨거운 작물이, 가을엔 단단한 작물이, 겨울엔 저장 작물이 강해.
> 8. (사계절 농부) 그래서 나는 여러 계절에 강한 작물들을 골고루 심어둬. 그럼 어떤 계절이 와도
>    밭 전체가 크게 흔들리지 않아 — 이게 바로 '포트폴리오'야.

**비유**: "포트폴리오는 다음 계절을 맞히는 게 아니라, 어떤 계절이 와도 버티도록 미리 골고루
심어두는 큰 농장이야."
**실생활 예시**: 용돈을 장난감 하나에 다 쓰지 않고 책, 저금, 나눔에도 나눠두면, 장난감이
금방 질려도 다른 즐거움이 남아있는 것과 비슷하다.
**게임 연결(기존 `EtfBasketGame.tsx` 그대로 재사용)**: "이번엔 회사뿐 아니라 다른 종류의
자산도 함께 담아서 바구니를 만들어보자."
**회고**: "여러 종류를 섞으니까 어떤 계절이 와도 밭이 크게 흔들리지 않았지? 그게 포트폴리오야."

### 5-2. 배치

새 라우트를 만들지 않는다. `components/rive/` 아래 `SeasonalFarmerCharacter.tsx`(신규,
`SquirrelGrandpaCharacter.tsx`와 동일한 패턴)를 만들고, `data/etfLabContent.ts`의
`storyScenes`(아직 코드에 연결 전이라면 `docs/concept-story.md` 문서 갱신까지만)에 5-1
내용을 추가한다.

## 6. 지식 도감 인터랙티브 위젯 — "경제 사계절 바퀴" (`docs/almanac-interactive.md` 확장)

`docs/almanac-interactive.md`가 이미 정의한 `AlmanacWidgetKey`/`AlmanacWidgetSlot` 구조를
그대로 재사용해 새 위젯 키 하나를 추가한다.

### 6-1. 스키마 추가

```ts
export type AlmanacWidgetKey =
  | /* 기존 15개 */
  | "economic-seasons-wheel"; // etf-lab
```

### 6-2. 위젯 설계 — `EconomicSeasonsWheel.tsx`

**조작**: 봄/여름/가을/겨울 4개 버튼 중 하나를 탭한다.
**변화**: 선택한 계절에 따라 5개 자산 아이콘(📈주식 🏠부동산 🪙금 🌾원자재 💰현금)이 각각
"쑥쑥 자람"/"보통"/"시듦" 애니메이션으로 반응한다(2장에서 확인한 실제 경제 이론을 단순화해
반영 — 아래 6-3 매핑표 참고). 화면 하단에는 **항상 고정된 문구**로 "다음 계절이 뭐가 될진
아무도 미리 알 수 없어요 — 그래서 여러 자산을 골고루 나눠 갖는 거예요"를 노출한다(3장 안전
원칙 2 반영, 절대 빠지지 않는 문구).
**기술**: `docs/almanac-interactive.md`와 동일하게 `motion`의 `animate`로 아이콘
`scale`/`y` 값을 계절별로 트랜지션. 캔버스 불필요, 순수 SVG/이모지 + `motion`으로 충분.

### 6-3. 계절 → 자산 반응 매핑 (단순화, 실제 경제 이론 기반)

| 계절(비유) | 실제 경제 국면 | 잘 반응하는 자산(애니메이션 "쑥쑥") |
|---|---|---|
| 봄 | 성장이 살아나고 물가는 안정적 | 📈 주식 |
| 여름 | 성장도 좋고 물가도 뜨겁게 오름 | 📈 주식, 🌾 원자재 |
| 가을 | 성장은 주춤한데 물가는 계속 오름(어려운 시기) | 🌾 원자재, 🪙 금 |
| 겨울 | 성장도 물가도 차갑게 식음 | 🪙 금, 💰 현금 |

부동산은 특정 계절에 강하게 편향시키지 않고 "보통" 반응으로 고정한다(임대료 기반 자산이라
실제로도 계절 구분이 뚜렷하지 않고, 이 앱이 부동산 시세를 예측하는 것처럼 보이지 않게 하기
위함). 이 표는 개발자 참고용 매핑이며, 화면에 "이 계절엔 이걸 사세요"라는 문장으로 절대
노출하지 않는다 — 아이콘 반응 애니메이션으로만 보여준다(1장 원칙 3 참고).

> **[각주]** 이 반응 테이블은 이후 `data/almanac/economicSeasons.ts`로 이동했다(`docs/fomo-portfolio-practice.md`
> 4-3 참고). `EconomicSeasonsWheel.tsx`와 `EtfBasketGame.tsx`의 포트폴리오 라운드(`PortfolioRoundGame.tsx`)가
> 함께 참조하며, 미니게임 채점용 `REACTION_MULTIPLIER`가 이 모듈에 추가로 정의되어 있다.

### 6-4. 배치

`data/almanac/etfLabAlmanac.ts`에 `interactiveWidgetKey: "economic-seasons-wheel"` 추가.
`docs/almanac-interactive.md` 7장의 우선순위 표 기준으로는 **P1(핵심 4개)에 준하는 우선순위**로
승격한다 — 이번 요청의 핵심 주제이기 때문이다.
